# Support

Use the project issue tracker for bug reports and feature requests:

https://github.com/luizgununes/codex-usage-bar/issues

Before opening an issue:

1. Update Codex Usage Bar and the official Codex CLI or OpenAI extension.
2. Run **Codex Usage: Refresh Rate Limit** from the Command Palette.
3. Check **View → Output → Codex Usage Bar** for the sanitized error message.

Do not include access tokens, `~/.codex/auth.json`, account responses, or private source code in reports.
